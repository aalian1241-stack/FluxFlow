# 🌿 FluxFlow — Habit Tracker

> ✨ Build better habits. Create better days. Become a better you.

FluxFlow is a clean, modern, and thoughtfully designed habit-tracking application built with Flutter. It helps you turn small daily actions into consistent routines by making habit creation, daily tracking, streak building, and progress discovery simple and enjoyable.

Whether you're trying to drink more water 💧, exercise regularly 🏋️, read every day 📚, practice mindfulness 🧘, or simply become more consistent, FluxFlow gives you a focused space to build habits without unnecessary complexity.

---

## 🌱 Why FluxFlow?

Building better habits doesn't have to be complicated.

FluxFlow focuses on the essentials: create the habits that matter to you, organize them into meaningful categories, complete them every day, and use simple insights to understand your progress.

The goal is simple:

**Small actions → Daily consistency → Stronger routines → Better progress 🚀**

---

## ✨ Features

- ✅ Create, edit, and delete habits
- 🗂️ Organize habits by category
- 🎨 Customize habit colors
- 🌿 Choose personalized habit icons
- 🔥 Track current and best streaks
- 📊 View completion progress
- 📈 Analyze your last 7 days
- 🔎 Search and filter habits
- 👋 Personalized onboarding
- 📱 Responsive Flutter interface
- 💚 Clean, light-green Material 3 design

---

## 🛠️ Built With

- 💙 Flutter
- 🎯 Dart
- 🎨 Material 3

---

## 🎯 Project Goal

FluxFlow was created with one idea in mind:

> **Make habit tracking simple enough that you actually want to use it every day.**

Instead of overwhelming users with dozens of features, FluxFlow keeps the experience focused on creating routines, completing them consistently, and seeing meaningful progress.
